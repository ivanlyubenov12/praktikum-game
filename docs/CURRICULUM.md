# Curriculum fit (7th grade, Bulgaria)

Subject: *Химия и опазване на околната среда*, 7th grade, 54 hours per year (curriculum in force from 2023/2024;
textbooks from Просвета, Булвест 2000, Анубис/Клет).

## Topic order (from published teaching materials)

chemical symbols → formulas → naming → valence → writing formulas → atomic and molecular mass → **chemical
equations** → sodium → sodium hydroxide (bases) → mass fraction → chlorine → hydrogen chloride / hydrochloric acid →
chlorine compounds → halogen group (simple substances and compounds) → acids → types of substances and reactions →
periodic table.

The game follows the alkali-metal chain (Na → Na₂O → NaOH → NaCl) and the chlorine/halogen reactions, and
generalises them to the other alkali metals and halogens, as requested.

## The two source schemes this version is built on

1. Sodium chain: `4Na + O₂ → 2Na₂O`, `Na₂O + H₂O → 2NaOH`, `NaOH + HCl → NaCl + H₂O` (neutralisation),
   `2Na + 2H₂O → 2NaOH + H₂`, `2Na + Cl₂ → 2NaCl`.
2. Chlorine scheme: `Cl₂ + H₂ → HCl`, no reaction with O₂, `Cl₂ + metal → salt`, `Cl₂ + H₂O → HCl + HClO`,
   `Cl₂ + NaOH → NaCl + NaClO`.

## Templates and how sure the fit is

`M` = Li, Na, K, Rb, Cs. `X` = F, Cl, Br, I (restricted where noted).
"Source" = seen in a 7th grade textbook, test, olympiad or school worksheet. "Pattern" = same reaction type seen
with a neighbouring substance. "My choice" = fits the topics but I found no matching 7th grade source. **Check
"pattern" and "my choice" rows with the teacher.**

## Element coverage

- **Na, K, Li**: appear in 7th grade equations.
- **Rb, Cs**: appear as names and properties in 7th grade tests (alkali group). Equations with them are an
  extension by analogy: all alkali metals are I valent, so the coefficients are the same.
- **F**: appears in the halogen group. Only used in reactions that are valid for it (see `docs/SCIENCE.md`).

## Left out on purpose

- Organic chemistry (CH₄, C₃H₈): removed in an earlier version.
- Redox balancing, ions, charges, half-reactions.
- H₂SO₄, HNO₃ as reactants, other salts, other metals except Al and Ca in a few fixed reactions.
- Fe + Cl₂ → FeCl₃ (was in the first 3D version; dropped to keep the focus on alkali metals and halogens).
